# Neuropost Bot

Бот для нейропостинга: слушает список чужих Telegram-каналов, переписывает
новые посты через Claude API и автоматически публикует в ваш канал.

## Как это работает

- **Telethon (userbot)** — заходит под вашим личным Telegram-аккаунтом и
  слушает список каналов-источников в реальном времени. Обычный бот не может
  читать чужие каналы, если он не админ в них — поэтому нужен именно userbot.
- **Groq API** — переписывает текст поста, сохраняя факты, но меняя
  формулировки. Быстро и дёшево.
- **python-telegram-bot (Bot API)** — публикует готовый пост в ваш канал от
  имени бота.
- **SQLite** — хранит хэши уже обработанных постов, чтобы не дублировать
  одну и ту же новость из разных источников.

## Установка на VPS

### 1. Подготовка сервера

```bash
sudo apt update && sudo apt install -y python3 python3-venv python3-pip
```

### 2. Скачайте проект на сервер и создайте виртуальное окружение

```bash
cd ~
# скопируйте папку neuropost_bot на сервер (scp, git и т.д.)
cd neuropost_bot
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

### 3. Настройте конфигурацию

В архиве уже лежит готовый файл `.env` с вашим ключом Groq — просто
проверьте и допишите остальные поля:

```bash
nano .env
```

Заполните:
- `TG_API_ID` и `TG_API_HASH` — получить на https://my.telegram.org
  (Api development tools → создать приложение).
- `BOT_TOKEN` — создать бота у [@BotFather](https://t.me/BotFather),
  скопировать токен.
- `TARGET_CHANNEL` — юзернейм вашего канала (`@my_channel`). **Бота нужно
  добавить в канал как администратора** с правом публикации сообщений.
- `GROQ_API_KEY` — уже вписан. Модель по умолчанию `llama-3.3-70b-versatile`,
  можно сменить через `GROQ_MODEL` (например, на `openai/gpt-oss-20b`).
- `SOURCE_CHANNELS` — список каналов-источников через запятую
  (`@channel1,@channel2`). Ваш личный аккаунт (тот, под которым авторизуется
  userbot) должен быть подписан на них или они должны быть публичными.

⚠️ **Важно про ключ**: раз он был отправлен текстом в чат, стоит после
настройки зайти на https://console.groq.com/keys, удалить этот ключ и
выпустить новый — так безопаснее.

### 4. Первый запуск (авторизация userbot)

```bash
source venv/bin/activate
python main.py
```

При первом запуске Telethon попросит:
1. Номер телефона вашего аккаунта.
2. Код из Telegram (придёт в само приложение).
3. Пароль двухфакторки, если она включена.

После этого создастся файл `userbot.session` — при следующих запусках
авторизация не потребуется. **Файл сессии — это фактически ключ доступа к
вашему аккаунту, никому его не передавайте.**

Проверьте, что при появлении нового поста в источниках бот подхватывает его
и публикует переписанный вариант в ваш канал. Остановите (`Ctrl+C`).

### 5. Настройка автозапуска через systemd

Отредактируйте `neuropost.service`, заменив `YOUR_LINUX_USER` на ваше имя
пользователя на сервере, затем:

```bash
sudo cp neuropost.service /etc/systemd/system/
sudo systemctl daemon-reload
sudo systemctl enable neuropost
sudo systemctl start neuropost
```

Проверить статус и логи:

```bash
sudo systemctl status neuropost
journalctl -u neuropost -f
```

## Подпись под постами

Каждый опубликованный пост автоматически получает подпись-ссылку в конце:

```
Инфач! Подписаться!
```

— кликабельную ссылку на ваш канал (`https://t.me/+UE0bYyh4qUxhZGEx`).
Настраивается в `main.py`, переменная `CHANNEL_SIGNATURE`. Чтобы поменять
текст или ссылку, отредактируйте эту строку:

```python
CHANNEL_SIGNATURE = (
    '\n\n<a href="https://t.me/+UE0bYyh4qUxhZGEx">Инфач! Подписаться!</a>'
)
```

## Настройка стиля переписывания

Промпт для переписывания находится в `rewriter.py`, в переменной
`SYSTEM_PROMPT`. Отредактируйте его под стиль вашего канала: тон, длину,
использование эмодзи, форматирование (жирный шрифт, ссылки и т.д.).

## Что можно доработать дальше

- **Фильтрация по ключевым словам** — публиковать только посты на нужную
  тематику (проверка перед вызовом LLM).
- **Модерация** — вместо прямой публикации отправлять черновик себе в
  личку и публиковать по нажатию кнопки.
- **Форматирование под Telegram HTML** — просить модель сразу возвращать
  `<b>жирный</b>` там, где нужно выделение.
- **Несколько источников с разными промптами** — если разные каналы нужно
  обрабатывать по-разному.
- **Rate limiting** — если источников много и посты идут часто, добавить
  очередь (например, `asyncio.Queue`), чтобы не упереться в лимиты Anthropic
  API или Telegram.

## Важно

- Дословное копирование чужих текстов без переработки может нарушать
  авторские права источника — данный бот специально переписывает текст
  своими словами, а не просто пересылает его.
- Файл сессии userbot (`userbot.session`) даёт полный доступ к вашему
  личному аккаунту Telegram — храните его так же бережно, как пароль.
